# 英语启航 EnglishQuest 🚀

一个零基础学英语的跨平台应用：从字母音标开始，用约 22 个月（670 天）走到英语四级水平。可在设置中切换为两年（730 天）或一年（365 天）。
界面生动有趣，包含任务奖励、连续打卡、成就徽章、单词配对游戏和语音朗读，学习数据保存在本机。

> 技术形态：PWA（渐进式网页应用）。一套代码，Windows 和安卓都能"安装到桌面/开始菜单"，安装后全屏运行、可离线使用。它不是 APK/EXE 安装包，但使用体验接近原生应用。

## 功能一览

- **按你的真实情况固定排的每日计划**：你的起点已确定为「只认识字母，不认识音标、单词、语法、句子」，因此**不提供中学/大学基础切换，也不会跳过任何启蒙阶段**；每日时长可选 30 / 33 / 45 / 60 分钟（最低 30 分钟，低于此时长无法保证完整覆盖）。每天 4 项固定任务 + 到期复习：字母音 → 音标 → 自然拼读 → 语法 → 四级题型。完整计划为 **670 天（22 个月）**，逐日推进不跳课；同一天打开内容一致。校核确认：走完整计划会覆盖**全部 4642 词**和全部四级题型题库。
- **智能复习进计划**：学过的单词、语法、音标和字母会按 1 / 3 / 7 / 15 天的间隔自动排进当天计划，成为第 5 项「今日到期复习」，点开即练。答对拉长间隔，答错第二天再来；连续 4 次答对后该项「毕业」，不再无限占用每日额度；每天最多 36 项，校核确认期末无积压。计划页能看到未来 7 天各自的复习项。
- **错词手写巩固**：到期复习中答错的单词会自动收集（最多 3 个），答题结束后逐个弹出描红手写，写完才结束本轮复习；答对的词快速过，不浪费时间。
- **每天排什么**：第 1–6 天补字母在单词里的发音（不重复教字母名），第 7–28 天每天 2 个音标，29–44 天音标巩固，45–90 天自然拼读；第 91 课程日起每天 1 讲语法，并按**八天循环**训练**四级听力 → 仔细阅读 → 选词填空 → 长篇阅读匹配 → 写作 → 翻译 → 口语 → 完整真题模考**，每种题型的题库按顺序全部轮完，不会只反复抽到固定几篇。这是按你「只认识字母」的情况锁定的路线，不会跳级。单词按实际新词数连续推进并环绕覆盖全词库，听力按「辨字母 → 辨音标 → 听词选义 → 四级新闻/对话/讲座」逐级推进。**阅读/写作/翻译/完整模考当天会自动减少新词，首页每个任务都显示预计分钟数，顶部显示今日预计总时长**；完整模考仍保留完整流程，选 45 分钟档会更从容。
- **21 个学习模块**：字母音、单词卡片、音标启蒙、自然拼读、语法课堂、基础听力、阅读闯关、口语跟读、单词配对游戏、复习巩固；以及**手写练习板、默写测验、四级词库默写、情景口语对话、四级听力、四级阅读、四级写作、四级翻译、四级真题模考、四级错题本、中英互译**。只多不少。
- **完整四级词库（4642 词）**：内置《大学英语四级考试大纲》4615 词（去重 4540），连同原有基础词共 **4642 个不重复单词**，其中 3100+ 带音标。**全部 4642 词都配了可朗读的学习例句和中文提示**，档案与 Excel 导出不再出现空白例句。词库离线可用，无需联网查词。
- **完整四级题型训练**：四级听力（12 段新闻/对话/讲座）、四级阅读（选词填空 6 组 30 空、长篇匹配 3 组、仔细阅读 6 篇）、四级写作（12 个话题 + 范文 + 中文意思 + 可套用词组）、四级翻译（12 篇汉译英 + 参考译文 + 词组提示）、完整真题模考（听力 5 题 + 词汇语法 5 题 + 阅读 2 题 + 翻译 1 篇 + 写作 1 篇，分项给出参考分）。
- **四级错题本**：听力、阅读、模考中答错的题自动收集，支持 🔊 重听、重做、移除；重做答对后自动移出错题本。
- **中英互译**：「学习 → 中英互译」支持英文→中文、中文→英文；覆盖 4642 词与四级范文、翻译参考、阅读短文、听力原文中的句子；结果可朗读，单词可一键加入已学词并进入复习计划。全部离线可用。
- **我的学习档案 + Excel 导出**：按已学天数自动汇总学过的全部内容，分「单词 / 音标 / 字母音 / 自然拼读 / 语法 / 句子」六类查看，含音标、中文释义与例句；支持关键词搜索、点 🔊 朗读、分类切换。单词页可切换到「完整四级词库（4642 词）」。点「📊 导出学习内容」会弹出**类别选择框**：六类可任意勾选（每个类别显示实际条数与一条内容示例），单词可选「已学单词」或「完整四级词库」；「全选 / 全不选」一键切换。导出的 `.xls` 每个类别一个工作表，表头即完整内容字段（序号、单词、音标、中文释义、例句、例句中文、学习天数、来源等），**不是数量统计**，数量只放在最后的「导出说明」表；Excel/WPS 可直接打开，离线可用。从学习页入口或首页「已掌握单词」卡片进入。
- **手写练习板**：用手指、触控笔或鼠标写字母和单词；带浅灰描红底稿、颜色/粗细切换、撤销、清空、保存图片，默认前几项就是"今日单词"。
- **默写测验（自己核对）**：「学习 → 默写测验」按当天 4 个单词出题；「学习 → 四级词库默写」从全部 4642 词随机抽 4 个单词。两者都是一次 10 题，覆盖单词、字母音、语法句型三类。每题只给发音朗读和中文提示（不显示答案），手写后点「核对答案」查看正确答案，由你自己判断写对还是写错——**不再使用 OCR 自动识别或自动判分**。默过的词自动记为已学并出现在学习档案，自己标错的会加入复习队列，次日按遗忘曲线再考；也可以点「返回重写」。默写属自由学习区，不发放积分。
- **激励机制（按对错计分）**：XP 经验值、等级、连续打卡、11 枚成就徽章、答题撒花动画、每日鼓励语。**仅每日计划内任务发放经验值，按「答对题数 ÷ 总题数 × 任务最高分」计算**：例如某项 20 XP、共 4 题，答对 1 题得 5 XP、答对 2 题得 10 XP、全对得 20 XP。当天重做只补差额、不重复发放，最多拿满任务最高分；**重新打开/刷新页面也不会把已发积分清零再领一次**，任务卡显示「最高 +N XP」。写作、翻译、完整模考按完成度/正确率折算。手写板、自由默写、四级词库浏览、档案复习、口语对话、中英互译、写作/翻译自由练习、模考等自由学习区**不发积分**。
- **断签轻处罚**：断签后连续天数清零，次日计划自动追加「补做」任务（最多补 2 天，更早自动翻篇）；不倒扣经验值，但有欠账时拿不到当日全勤 +30 XP。断签 3 天以上后重新完成全天任务，额外 +40 XP 并解锁「回归勇士」徽章。
- **视频微课讲解**：单词、音标、语法，以及每道模考题答完后，都有「🎬 视频讲解」入口——分步骤动画课堂 + 字幕 + 语音解说，离线也能用，可暂停/切段/重播。也可在「我的」里填自己的视频链接：mp4/webm 直链直接播放，普通网页链接显示跳转按钮。
- **人声自然度优先**：「我的 → 人声自然度」默认开启。开启后优先挑选设备里最像真人的语音（Natural / Neural / Aria / Google 等），去掉机械变调，按句意在句号、问号处自然停顿；长句会分段朗读。也保留 5 种内置风格语音（温柔女声 / 沉稳男声 / 活泼童声 / 清晰播报 / 慢速教学）和系统语音列表，可随时切换并试听。
- **我的专属语音包（录音识别音色）**：在「 my / 我的 」页点「开始录一段」，朗读屏幕上的英文句子（约 5 秒）。APP 会在本机分析你声音的**音调高低（基频）、语速快慢、男女声**，自动生成专属音色；之后**所有单词/例句朗读和答题对错提示音**都会套用这个音色（中英文都生效），不用逐词录音。可试听「我的声音」、听回原声、重新录制或删除。录音与识别只在本机完成，不上传。
- **答题提示音单独设置**：答题对/错的人声可与朗读声音不同；可选「跟随朗读」「系统原声」或任意内置风格。台词风格有**幽默搞笑（默认）**、温柔鼓励、简洁干脆三种，语言可在**中文 / English / 中英混合**间切换，可试听；答完题屏幕上也会显示那句台词。人声可在设置里开关。
- **情景口语对话（按进度分层）**：从「学习 → 口语对话」进入，系统根据当前天数与已学单词数自动匹配启蒙档 / 积累档 / 进阶档，并每天轮换情景（见面、文具、食物、朋友、周末、梦想工作、健康、互联网、家乡等 11 个场景）。系统用你设定的英语音色提问并给中文提示，你用麦克风回答（不支持语音识别的设备可输入英文），按关键词命中判分；可随时看参考回答（英文 + 中文意思）或跳过，自己说过的句子下方也会显示对应中文意思。属自由口语练习，不发放积分；累计统计保存在本地。
- **手机横屏与全屏书写**：界面适配横屏矮屏（顶栏/导航压缩、模块多列、弹层与书写区按视口高度自适应）。手写板和默写测验均提供「⛶ 全屏书写」按钮，安卓/电脑调用系统全屏（可旋转横屏），iOS 不支持时用铺满模式兜底；按 Esc 或再点按钮退出，退出后笔迹保留。书写坐标按布局尺寸计算并抵消弹窗缩放/浏览器缩放，横竖屏切换或进入全屏时自动重建画布并按比例保留已写笔画，手指点与笔迹严格对齐（修复横屏「写 A 处显示在 B 处」的错位）。
- **语音功能**：使用系统内置英语语音朗读单词、例句、听力和课文；安卓/Windows 均可用（需系统安装英语语音包）。口语跟读与情景对话支持麦克风识别评分（浏览器支持时）。
- **数据管理**：进度保存在浏览器本地，支持导出/导入 JSON 备份，重置进度。

## 在 Windows 电脑上安装

1. 确保已安装 Microsoft Edge 或 Chrome 浏览器。
2. 在本文件夹打开命令行（地址栏输入 `cmd` 回车），运行：

   ```
   python -m http.server 8080
   ```

3. 打开浏览器访问 `http://localhost:8080`。
4. 点击地址栏右侧的"安装此应用"图标（或浏览器菜单 → 应用 → 安装此站点为应用）。
5. 安装后可从开始菜单/桌面直接启动，离线也能打开。

> 也可把这个文件夹部署到任意静态网站托管服务，用 https 地址打开后安装。

## 在安卓手机上安装

1. 把本文件夹部署到任意支持静态网站的托管服务（如 GitHub Pages、Netlify、Vercel、腾讯云 CloudBase 静态托管等），得到 https 地址。
2. 用手机 Chrome 浏览器打开该地址。
3. 点击右上角菜单 → "安装应用" 或 "添加到主屏幕"。
4. 桌面出现"英语启航"图标，点开即全屏使用；首次联网打开后即可离线学习。

> 如果只是想在自己电脑和手机上局域网测试，可在电脑上运行 `python -m http.server 8080`，
> 手机访问 `http://电脑IP:8080`（部分安卓浏览器允许添加到主屏幕；完整 PWA 安装需要 https）。

## 使用提示

- 首次打开会让你选择开始日期和每天学习时长，之后每天打开首页就能看到当天任务。
- 完成全部每日任务有额外 30 XP 奖励；连续打卡能解锁徽章。
- "我的"页面可以修改开始日期、时长、语速，或导出/导入学习进度。
- 语音依赖系统英语语音包；若没有声音，请在系统设置中安装英语（美国）语音。
- 图标可用 `python make_icons.py` 重新生成。
